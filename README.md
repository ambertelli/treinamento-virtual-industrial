# Treinamento Virtual Industrial

Aplicação web de treinamento industrial interativo em português.

## Desenvolvimento

- Node.js 20+
- `npm install`
- `npm run dev`
- `npm run build`

## Publicação

O workflow do GitHub Actions compila o projeto e publica o conteúdo estático no GitHub Pages quando houver push na branch `main`.

## Segurança e validação técnica

Os módulos são uma estrutura didática. Instruções de operação, parâmetros, imagens e procedimentos de segurança devem ser conferidos com o manual oficial da máquina e validados por responsável autorizado antes de serem usados em treinamento operacional.
